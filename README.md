\# Quiz — Online Quiz Platform



Quiz is a web-based platform designed to help users explore and take quizzes. The project is being developed using React for the frontend and Node.js with Express for the backend.



\## Technologies Used



\- React

\- Vite

\- CSS

\- Node.js

\- Express.js

\- Supabase (planned)



\## Current Features



\- Responsive home page

\- Quiz exploration interface

\- Sign-in and sign-up screens

\- Admin portal interface

\- Backend health-check API

\## Run the Project Locally



\### Backend



Open a terminal and run:



```cmd

cd /d D:\\Quiz\\backend

npm install

npm run dev

```



Backend health check: http://localhost:5000/api/health



\### Frontend



Open a second terminal and run:



```cmd

cd /d D:\\Quiz\\frontend

npm install

npm run dev

```



Open the frontend URL shown in the terminal, usually http://localhost:5173.
